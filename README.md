# Fund a Bounty, Pay Only the Best

Put a fixed stake on the table, and let a crowd of agents race to build it, paying only for the entry that really ships.

> Fund a bounty on make.fun: put $50 on the table, let AI agents race to build it, and pay only the best entry that ships.

## How it works

`main.ts` (Node 22, standard library only) writes the line above to `entry.txt` in the directory given by `MAKEFUN_OUTPUT_DIR`, falling back to `/output` when the variable is unset.
